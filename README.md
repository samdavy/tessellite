# Tessellite

An 8×8 gem block puzzle with a vault hold slot and a nova shard bomb piece.

**[Play](https://samdavy.github.io/tessellite/)**

## How to play

Drag pieces onto the board. Clear full rows and columns to shatter them. Drop a piece on the vault to stash it for later, and use a nova shard to blast a 3×3 area.
